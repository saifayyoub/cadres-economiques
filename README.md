# cadres-economiques

Interactive 100-question exam for Moroccan public-procurement decree 2.22.431.

This repository contains the original Cadres_Economiques.html served unchanged as index.html.

## Vercel

Import this repository in Vercel with the default static settings:

- Framework Preset: Other
- Build Command: (empty)
- Output Directory: (empty / .)
- Root Directory: .

Vercel will serve index.html at the site root. No build step is required.
